Removing the next failure edge is not the same as conditioning on eventual success. Paths that look safe now may fail later.

Closed cycles can avoid every terminal forever. The solver identifies that mass before it solves the remaining exact linear system.

Time given success can be finite even when unconditional time to success is infinite. An impossible event has no conditional mean.
